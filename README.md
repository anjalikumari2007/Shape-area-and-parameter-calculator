# Shape-area-and-parameter-calculator
The Shape Area &amp; Perimeter Calculator is a simple C++ project developed using Object-Oriented Programming (OOPS) concepts. It calculates the area and perimeter of three shapes: Circle, Rectangle, and Triangle.


The program uses a menu-driven interface that allows users to select a shape, enter its dimensions, and view the calculated area and perimeter.

# Features

Calculates the area and perimeter of a circle.

Calculates the area and perimeter of a rectangle.

Calculates the area and perimeter of a triangle.

Uses a menu-driven console interface.

Checks for invalid dimensions.

Allows users to perform multiple calculations until they choose to exit.

# OOPS Concepts Used

Classes and Objects: Each shape is represented using a class.

Inheritance: Circle, Rectangle, and Triangle inherit from the Shape class.

Abstraction: The Shape class defines common functions for calculating area and perimeter.

Virtual Functions: The area() and perimeter() functions are declared as virtual functions.

Function Overriding: Each derived class provides its own implementation of the functions.

Runtime Polymorphism: A base-class pointer is used to call the appropriate functions for each shape.

Encapsulation: Shape dimensions are stored as private data members.

# Technologies Used

Programming Language: C++

Libraries: iostream and cmath
